# 💰 AIレシートスキャン搭載・共同家計簿アプリ (Two-User Ledger App)

パートナーや家族と共同で生活費を管理・折半するためのWebアプリケーションです。
日常の支出の記録から、面倒な月末の精算計算、固定費の自動登録などを一元管理できます。さらに、**Google Gemini APIを活用したAIレシート解析機能**を搭載しており、入力の手間を大幅に削減します。

---

## 🌟 主な機能 (Features)

1. **AIレシートスキャン (Gemini API 連携)**
   - スマホなどで撮影したレシートの画像をアップロードするだけで、AIが「金額」「店舗名」「日付」「品目」を自動で読み取り、入力フォームに自動補完します。
2. **リアルタイム精算カード (Settlement Card)**
   - 登録された支出データから、「誰が誰にいくら支払えば、きれいに折半（あるいは設定した比率）になるか」を常に自動で算出し、ワンクリックで精算済みにできます。
3. **ダッシュボード & グラフ可視化**
   - 月ごとの支出推移や、カテゴリごとの割合をインタラクティブなチャート（Recharts）で表示します。
4. **固定費テンプレート機能**
   - 家賃や電気代、サブスクリプションなど、毎月発生する固定費を登録しておくことで、毎月自動的に支出として反映されます。
5. **モバイル対応 & PWA (Progressive Web App) 対応**
   - レスポンシブデザインにより、スマートフォンからも快適に操作可能。PWA対応により、スマホのホーム画面にアプリアイコンを追加してネイティブアプリのように起動できます。

## 💡 設計・実装のポイント (Engineering Highlights)

本アプリケーションの設計および実装における主な工夫や特徴は以下の通りです。

### 1. Gemini APIを用いたAIレシート解析の実装
- 単なる文字認識(OCR)ではなく、Gemini APIのマルチモーダル機能を利用して、レシート画像から「店舗名」「合計金額」「購入日時」「品目」を**構造化されたJSONデータとして直接抽出**するプロンプト設計を行いました。これにより、パースエラーの少ない安定した入力を実現しています。

### 2. クリーンな設計とリファクタリング (Privacy by Design)
- **データベース設計の抽象化**: 開発初期段階ではユーザー名がコードやデータベースに直接ハードコーディングされていましたが、将来的な複数アカウント対応やセキュリティ（個人情報の排除）を考慮し、データベース側では不変のシステムID（`user1` / `user2`）のみでデータを保持するようリファクタリングしました。
- **表示名の動的マッピング**: 画面に表示されるユーザー名は設定画面から動的に変更でき、フロントエンドとバックエンドの間で同期されます。これにより、データベースの一貫性を保ちながら、プライバシー保護と使いやすさを両立させています。

### 3. Docker Compose による容易な開発環境構築
- バックエンド、フロントエンド、PostgreSQL、pgAdmin をコンテナとしてオーケストレーションし、ローカルマシンにJavaやNode.jsをインストールしていなくても、`docker-compose up` コマンド一つで即座にアプリを起動・テストできる環境を構築しました。

## 🚀 ローカルでの起動方法 (Getting Started)

### 1. 前提条件
- **Docker** および **Docker Compose** がインストールされていること。
- **Gemini API の API キー** を取得していること。（Google AI Studio から無料で取得可能です）

### 2. 環境変数の設定
`docker` ディレクトリ内に `.env` ファイルを作成し、取得した Gemini API の API キーを設定します。

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
```

### 3. アプリケーションの起動
プロジェクトのルートディレクトリで以下のコマンドを実行します。

```bash
docker compose -f docker/docker-compose.yml up --build -d
```

### 4. アクセス
起動後、ブラウザで以下のURLにアクセスしてください。

- **フロントエンド（アプリ本体）**: `http://localhost:3000`
- **バックエンド API**: `http://localhost:8080`
- **pgAdmin (データベース管理画面)**: `http://localhost:8081`
  - ログイン情報: `admin@example.com` / `admin`
